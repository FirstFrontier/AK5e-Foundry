AK5e 1st Edition v1.3.1 — Foundry VTT source index

These files are an exact chapter split of the supplied Homebrewery source.
The YAML metadata and CSS preamble were intentionally excluded; they are layout/site
configuration rather than game rules. Homebrewery markup inside the chapters is retained
because it can contain meaningful rule tables, stat blocks, and callout content.

Recommended Codex workflow:
1. Read this index and the relevant chapter file only.
2. Treat the source text as the rules authority; do not invent missing mechanics.
3. When a rule references another chapter, load that chapter before implementing it.
4. Keep source headings in item/journal descriptions where useful for traceability.
